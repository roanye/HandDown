## Purpose:
Constitutes the frontend of the marketplace — an Expo-managed React Native app
(`Handdown_Frontend/`) covering onboarding/signup, the swipeable listing feed,
listing creation, profile, and messaging screens. See `Handdown_Frontend/app/`
for the screens and the root `README.md` for how to run it.

## ⚠️ Status: behind the latest local work

The code committed here is **not the newest frontend code**. More recent
frontend changes exist locally and have not been pushed to GitHub yet, so
some screens/calls here may not match what's been built or demoed more
recently, and may not line up cleanly with the current backend. If you have
newer local changes, push them to a branch and open a PR so this doesn't
drift further.
